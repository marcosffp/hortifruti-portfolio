# com.hortifruti.sl.hortifruti.controller.purchase

Endpoints do domínio de compras/vendas: cadastro de clientes, importação de compras (planilhas), agrupamentos de compras (`CombinedScore`) e edição/remoção de produtos de nota (`InvoiceProduct`).

| Arquivo | Tipo | Responsabilidade |
| --- | --- | --- |
| `ClientController.java` | `@RestController` (`/clients`) | `POST /clients/register` cadastra cliente; `GET /clients` lista todos; `GET /clients/{id}` busca por ID; `GET /clients/name/{name}` busca por nome; `PUT /clients/{id}` atualiza; `DELETE /clients/{id}` remove (`@PreAuthorize hasRole('MANAGER')`); `GET /clients/with-last-purchase` lista clientes com dados da última compra; `GET /clients/{id}/summary` retorna resumo do cliente; `GET /clients/for-selection` lista clientes em formato reduzido para seleção em UI. |
| `CombinedScoreController.java` | `@RestController` (`/combined-scores`) | `POST /combined-scores/create` cria agrupamento de compras; `POST /combined-scores/create-wildcard-billet` cria agrupamento avulso com produto coringa (R$1/kg) para clientes "somente boleto"; `GET /combined-scores` lista agrupamentos paginados (filtro opcional por cliente); `GET /combined-scores/last-per-client` retorna o último agrupamento de cada cliente; `DELETE /combined-scores/{id}` cancela agrupamento; `PATCH /combined-scores/confirm-payment/{id}` e `/cancel-payment/{id}` confirmam/cancelam pagamento; `GET /combined-scores/{id}/grouped-products` lista produtos agrupados do agrupamento. |
| `InvoiceProductController.java` | `@RestController` (`/invoice-products`), `@PreAuthorize hasRole('MANAGER')` | `PUT /invoice-products/{id}` atualiza um produto de nota; `DELETE /invoice-products/{id}` remove. |
| `PurchaseController.java` | `@RestController` (`/purchases`) | `POST /purchases/process` (`@PreAuthorize hasRole('MANAGER')`) processa upload de arquivo de compra (multipart); `DELETE /purchases/{id}` (`@PreAuthorize hasRole('MANAGER')`) remove compra; `GET /purchases/client/{clientId}/ordered` lista compras paginadas de um cliente; `GET /purchases/{id}/products` lista produtos de nota de uma compra; `GET /purchases/date-range` lista compras paginadas por intervalo de datas. |
| `NotaController.java` | `@RestController` (`/api/compras/notas`), `@PreAuthorize hasAnyRole('MANAGER', 'EMPLOYEE')` | `POST /api/compras/notas/upload` (multipart) recebe a foto de uma nota de compra, valida e salva temporariamente via `NotaUploadService`; `POST /api/compras/notas/extrair` (multipart) valida a foto e extrai itens/cliente/total via `GeminiExtractionService` (etapas 1 e 2 da captura via câmera/Gemini, ver spec — ainda sem matching de produto/checagem de consistência). |
