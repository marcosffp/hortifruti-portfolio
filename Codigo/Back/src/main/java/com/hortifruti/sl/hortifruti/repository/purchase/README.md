# com.hortifruti.sl.hortifruti.repository.purchase

Repositórios do domínio de compras/vendas: clientes, agrupamentos de compras (`CombinedScore`), produtos agrupados/de nota e compras individuais.

| Arquivo | Tipo | Responsabilidade |
| --- | --- | --- |
| `ClientRepository.java` | `JpaRepository<Client, Long>` | Entidade `Client`. `findByEmail`, `findByClientName`, `findByDocument` localizam cliente por email, nome ou documento (CPF/CNPJ). |
| `CombinedScoreRepository.java` | `JpaRepository<CombinedScore, Long>` | Entidade `CombinedScore`. `findByIdForUpdate` (`@Lock(PESSIMISTIC_WRITE)`) trava a linha para serializar emissão concorrente de boleto/NF; `findAllPendingWithBilletByClient`, `findAllPendingByClient`, `findOverdueUnpaidScores(By Client)`, `findOverduePendingScores`, `findAllOpenBillets`, `findAllOpenInvoiceOnly` (todos `@Query`) cobrem os diferentes recortes de agrupamentos pendentes/vencidos/abertos; `findByClientIdOrderByIdDesc` e `findAllByOrderByIdDesc` são paginados; `findLastGroupingPerClient` (`@Query` com subselect de `MAX(id)` agrupado por cliente) retorna o agrupamento mais recente de cada cliente; `findAllByYourNumber` e `findAllByOurNumberSicoob` (`@Query`) buscam por números de boleto (podem retornar múltiplos registros pois não são únicos); `findByInvoiceRef` e `findAllInvoiceRefsByClientId` (`@Query`) tratam referências de NF-e; `findByHasInvoiceTrueAndConfirmedAtBetween` (`@Query`) filtra agrupamentos faturados confirmados num período. |
| `GroupedProductRepository.java` | `JpaRepository<GroupedProduct, Long>` | CRUD simples de produtos agrupados; sem queries customizadas. |
| `InvoiceProductRepository.java` | `JpaRepository<InvoiceProduct, Long>` | Entidade `InvoiceProduct`. `deleteByCreatedAtBetween(LocalDateTime, LocalDateTime)` remove produtos de nota criados num período (usado em rotinas de limpeza). |
| `PurchaseRepository.java` | `JpaRepository<Purchase, Long>` | Entidade `Purchase`. `findTopByClientIdOrderByPurchaseDateDesc` busca a compra mais recente de um cliente; `sumTotalByClientId`/`sumTotalGroupedByClientId` (`@Query`) somam compras por cliente (o segundo, agrupado, retorna `List<ClientPurchaseTotal>` — projeção tipada via constructor expression, não `Object[]`); `findByClientIdAndPurchaseDateBetween` e `findByClientId` filtram por cliente/período; `deleteByCreatedAtBefore` remove compras antigas; `findByClientIdOrderByPurchaseDateDesc` e `...OrderByCreatedAtDesc` são paginadas; `findByIdIn(List<Long>)` busca em lote; `findByPurchaseDateBetweenOrderByPurchaseDateDesc` é paginada por período; `findByCreatedAtBetween` lista por data de criação. |
| `ClientPurchaseTotal.java` | `record` (projeção) | `(Long clientId, BigDecimal total)` — resultado tipado de `PurchaseRepository#sumTotalGroupedByClientId`. |
